# LOTO Procedure: Conveyor Motor CM-01

## 1. Isolation Points

| ID | Type | Location | Tag |
|----|------|----------|-----|
| BRK-12 | Breaker | Panel A, bay 3 | LOTO-Red-12 |
| VLV-04 | Valve | Steam line, N-22 | LOTO-Yellow-04 |
| PNEU-07 | Pneumatic | Air line to motor | LOTO-Blue-07 |

## 2. Verification Steps

1. Open BRK-12, apply red lock, tag with operator ID
2. Test for zero voltage at motor terminals with Fluke 87V
3. Verify pressure gauge at VLV-04 reads 0 PSI
4. Bleed pneumatic line at PNEU-07 until no flow
5. **Try-start the motor** — must not start

## 3. Authorized Personnel

Only personnel with current NFPA 70E qualified-electrical-worker card may perform LOTO:
- Shift Electrician (cert #: EE-2xxx)
- Maintenance Lead (cert #: ML-1xxx)
- Authorized Contractor (sponsor-approved)

## 4. Removal Procedure

1. Confirm all work complete and tools removed
2. Visual sweep of motor area
3. Remove PNEU-07 lock — restore pneumatic
4. Remove VLV-04 lock — slowly reopen valve
5. Remove BRK-12 lock — restore power
6. Notify production before restart

## 5. Emergency Procedure

If LOTO fails (unexpected re-energization):
- Call 911 immediately
- Do not re-enter equipment
- Report to Safety Manager within 1 hour
- Preserve locks and tags for investigation
- File NFPA 70E incident report
